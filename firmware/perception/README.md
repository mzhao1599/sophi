# Perception firmware (planned)

An ESP32 samples multiple ToF sensors and reports quality-tagged proximity zones. It supports local cues; it does not certify a clear path. Read [ESP32 firmware](../../docs/subsystems/esp32-firmware.md) and [interfaces](../../docs/interfaces.md).

Record sensor model, address/multiplexer wiring, zone geometry, calibration, threshold/hysteresis measurements, and fallback cue wiring here.
